## 创意核心

**不死的不是人，是斗笠。** 用一件信物串联三代人的牺牲，最后揭示"蓑帽之下可以是任何人"的震撼真相。

- **前3秒钩子**：血雨中的蓑帽大特写 + 染血的手缓缓拾起 + 旁白"江湖传说——存在一位不死的侠客"
- **情绪弧线**：苍凉悬念（0-8s）→ 悲壮牺牲（8-18s）→ 传承接力（18-32s）→ 宿命蒙太奇（32-45s）→ 震撼收束（45-62s）
- **视觉关键词**：暗紫暮色、残阳血色、蓑帽竹篾纹理、雨水血滴、剪影逆光、蓑衣猎猎
- **核心台词**："江湖传说，存在一位不死的侠客。蓑帽之下，可以是任何人。"
